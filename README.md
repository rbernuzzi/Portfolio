Oi, eu sou a Rebecca! Estudo Direito na FMU e atuo com Ouvidoria e Defesa do Consumidor. No dia a dia, descobri que adoro usar tecnologia e inteligência artificial para deixar a rotina jurídica mais simples, e este portfólio reúne o que construí nesse caminho.

## O que você vai encontrar

- **Relatório Gerencial de Produtividade:** a ferramenta que criei para registrar a rotina da equipe e acompanhar os resultados. É o meu case principal. [Abrir o relatório](https://rbernuzzi.github.io/relatorio-protocolos/) · [Visão da liderança](https://rbernuzzi.github.io/relatorio-protocolos/lideranca.html)
- **Justina:** um chatbot de demonstração que responde dúvidas internas sobre cadastros, contratos e assinaturas. [Conversar com a Justina](https://rbernuzzi.github.io/justina/)

## Como foi feito

Usei HTML, CSS e JavaScript puros, sem build e sem servidor. A página é um único `index.html`, com as imagens na pasta `img/`. Meus dados pessoais ficam no objeto `CONFIG`, no fim do arquivo, e os campos vazios simplesmente não aparecem na página.
